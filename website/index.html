THE PLAN, up front

Before anything is written, the app states exactly what gets flashed and how your data is treated. You confirm the plan — not a leap of faith.

📦

Full payload support

OTA payload.bin extracted with bundled payload-dumper-go and flashed per-partition, with clean/dirty flash choice and vbmeta disable-verity.

🔀

A/B aware

Dual-slot detection, custom recovery written to both slots, active-slot awareness, and pre-repair partition backups kept on your PC.

🚀

Guided two-stage install

Boot chain → recovery → the ROM installs itself via sideload → extras (GAPPS/Magisk) → first boot. Reboots are chained automatically.

🛡

Hard-brick guards

Anti-rollback consent, both-slot fallback warnings, locked-bootloader refusal, low-battery gate. The app argues with you before it lets you hurt the phone.

🗣

Plain-language failures

Fastboot/adb errors translated into human. Disabled buttons state exactly why. A low-battery popup at flash time, not a surprise.

🛠

Rescue tools

FRP erase, metadata wipe, misc erase, slot switch, fastbootd — each with an honest description and the EDL 9008 reality stated plainly.

📜

Full command logs

Every adb/fastboot call recorded, level filters, copy and diagnostics bundle. adb server cleaned up on exit.

🌗

Dark · Light · OLED · Auto

Four themes, reduce-motion toggle, expert mode when you need the raw edges. The app animates, but never fights Windows' motion settings.

⚠️ Real talk — read this once

  • Unlocking the bootloader wipes your device. Everything — apps, photos, data.
  • A wrong or interrupted flash can hard-brick the phone, with no software fix.
  • SR Flasher shows exactly what it writes before it writes it — but you choose what to flash.
  • Flashing is at your own risk. The app accepts no responsibility for hardware damage.

Questions people actually ask

Is it really free? Where's the catch?
MIT-licensed open source, forever. No accounts, no ads, no telemetry, no "pro" tier. The bundled tools (adb, fastboot, payload-dumper-go) are Apache/BSD licensed and credited in THIRD-PARTY-NOTICES.md.
Why does Windows / my antivirus show a warning?
The exe is unsigned (code-signing certificates cost money a free tool doesn't have yet). SmartScreen shows "unknown publisher" until enough installs build reputation. The code is fully open — build it yourself if you prefer.
Does it work on my phone?
It's built for A/B (seamless-updates) devices with an unlocked bootloader. POCO F7 (onyx) is verified end-to-end. Other A/B devices follow the same flow — report your result and it gets added to the list.
Can it recover a hard-bricked phone?
No — and it says so instead of pretending. Qualcomm EDL (9008) requires an authorized flasher with credentials. What it CAN do: prevent you getting there, back up recovery before repair, and switch slots on a device stuck on a bad slot.
Does it collect anything?
No telemetry, no accounts. The only network call is an optional daily check of the public GitHub releases API — and it sends nothing but a plain request.
Can I break the app by wrong settings?
The guided route is the safe one. Expert mode exposes per-partition selection and vbmeta verity options — labeled "keep OFF unless you know exactly why you need it".
